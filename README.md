Detects phishing by understanding **intent**, not just links.

## 🚀 How to Run

### 1. Backend (FastAPI)
- `cd backend`
- `pip install -r requirements.txt`
- Run using the Python script:
  `python backend.py`
- **OR** run directly via Uvicorn (standard):
  `uvicorn backend:app --reload`
  
  `127.0.0.1:8000 docs` -> open on new tab for checking (surety backend is running).

### 2. Frontend
- Open `frontend/index.html` in your browser (or use Live Server in VS Code).

## 🛠️ Tech Stack
- **Python / FastAPI** (Backend Logic)
- **Three.js** (3D Visuals)
- **Tailwind CSS** (UI)
